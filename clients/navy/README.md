# Navy Template Tools

Placeholder for Navy-specific Word template and publishing tools.

Navy is an active client alongside NIST. Scripts for Navy template standards, style architecture, and document assembly will be added here as they are developed.

## Structure

Follow the same pattern as `../nist/`:

- Shared Navy template tools in this directory
- Document-set-specific build tools in subfolders as needed

## Generic Tools

Client-agnostic OOXML inspection and manipulation tools are in `../../word/`. Use those for initial template analysis before building Navy-specific tooling.
