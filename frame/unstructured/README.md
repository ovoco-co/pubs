# Unstructured FrameMaker Tools

Placeholder for unstructured FrameMaker template tooling.

Unstructured FrameMaker uses paragraph formats, character formats, table formats, master pages, and reference pages to control document appearance. Content is formatted text, not XML elements.

## Planned Tools

- Master page generators
- Paragraph catalog builders (paragraph, character, table format definitions)
- Import format mapping tools (for importing Word content into FrameMaker templates)
- Cross-reference format definitions
- Variable definitions for running headers/footers
