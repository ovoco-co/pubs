# DITA Publishing through FrameMaker

Placeholder for FrameMaker-based DITA publishing tools.

This directory covers publishing DITA content through Adobe FrameMaker's structured authoring mode. FrameMaker uses an Element Definition Document (EDD) mapped to the DITA DTDs to render DITA topics and maps as formatted output (PDF, print).

For converting Word content INTO DITA format, see `../../../dita/`.

## Planned Tools

- EDD templates for DITA topic types (concept, task, reference)
- Read/write rules mapping DITA elements to FrameMaker formatting
- Template pages for DITA map-based publishing
- Publish settings for PDF output from DITA maps
