# S1000D Publishing through FrameMaker

Placeholder for FrameMaker-based S1000D publishing tools.

S1000D is an international specification for technical publications, widely used in military, aerospace, and defense. FrameMaker's structured mode can author and publish S1000D data modules using an EDD mapped to S1000D schemas.

## Planned Tools

- EDD templates for S1000D data module types
- Read/write rules for S1000D elements
- BREX (Business Rules Exchange) validation templates
- Publishing stylesheets for S1000D output
