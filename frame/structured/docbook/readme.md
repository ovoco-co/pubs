# DocBook Publishing through FrameMaker

Placeholder for FrameMaker-based DocBook publishing tools.

DocBook is a book-oriented XML standard for technical documentation. FrameMaker's structured mode can author and publish DocBook documents using an EDD mapped to the DocBook DTD/schema.

## Planned Tools

- EDD templates for DocBook elements (book, chapter, section, article)
- Read/write rules mapping DocBook elements to FrameMaker formatting
- Publishing templates for DocBook-to-PDF output
